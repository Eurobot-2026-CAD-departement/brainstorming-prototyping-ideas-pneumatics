# Brainstorming & prototyping — pneumatics

A design idea based on **pneumatic actuation** for handling the crates.

## Contents
- `pneumatics.SLDASM` — assembly, with base, 20x20 profile and crate stopper
- `hinge 1/`, `hinge 2/` — two hinge variants
- `piece util/` — reusable parts (pumps, fittings, ...)

Part of the CAD work of the **Aerobotix (INSAT, Tunisia) Eurobot 2026 team** — see the [organization](https://github.com/Eurobot-2026-CAD-departement) for the other repositories.
